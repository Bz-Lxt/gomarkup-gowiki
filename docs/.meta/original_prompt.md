我想用Go语言实现一个现代协作式 Wiki 与知识库系统 (类似Mini Notion /语雀)

业务背景：支持多人在线协同、富文本/Markdown 编辑、文档树级管理的团队知识库。

前端页面（Vue 3 / Svelte）：工作台首页：最近浏览、我的收藏、团队动态。无限层级文档树：左侧支持拖拽调整目录层级的树状组件。富文本/Markdown 编辑器：集成 Tiptap 或 Quill，支持图片上传、代码高亮、历史版本对比（Diff 展示）。

Go 后端核心实现：冲突解决与协同（简化版）：利用 WebSocket 结合加锁机制（或简单的 OT/CRDT 协同算法核心），处理多人同时编辑。全文检索：集成 Bleve（Go 原生全文检索库）或 ElasticSearch，对文档内容进行深度分词搜索。

版本控制系统：每次保存生成快照，支持回滚到历史任意版本。

文件数与代码量：约 30+ 个 Go 文件，代码量约 5500 - 8000 行。
